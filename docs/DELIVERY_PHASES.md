# Delivery Phases

Status: Draft

## Milestone 0: Product Definition (Complete)

Finalize scope, workflow, content blocks, roles, acceptance criteria, and open
client dependencies.

## Milestone 1: Engineering Foundation (Complete)

Create repository structure, shared schemas, environments, deployment skeletons,
quality checks, and secrets strategy.

## Milestone 2: Creator Editorial Prototype (Functionally complete; final security verification pending)

Build the demo directory, Creator forms and reports, editor widget, Blueprint,
review queues, preview, and editorial dashboards.

Creator delivery artifacts are a DS structure file, a separately built widget
ZIP, seed data/configuration files, and an installation checklist.

## Milestone 3: Publishing Backend (Implemented locally; deployment pending)

Build Catalyst endpoints, validation, immutable publication, media mappings,
scheduling, retries, audit logs, and Creator callback reconciliation. Vercel
revalidation moves to the separate public frontend phase.

## Milestone 4: Public Blog

Build and verify the Insights frontend, search and taxonomy views, SEO, feeds,
accessibility, performance, redirects, and error states.

## Milestone 5: End-to-End Validation

Test every workflow path, failures, retries, permissions, browser behavior, and
acceptance criteria. Demonstrate the complete product to the client.

## Milestone 6: Client Integration and Launch

Inspect the client's Creator application, map existing records, implement in
Development, validate in Stage, deploy client-owned infrastructure, and launch.

## Milestone 7: Website Revamp

After sitemap approval, add structured page management, migrate website content,
preserve URLs, configure redirects, and complete full-site launch and stability.
